> **Aerospace Engineer focused on propulsion, mechanical design, computational analysis, and experimental hardware.**


## 🔥 LUME-X1

### Liquid Rocket Engine

A small pressure-fed liquid rocket engine developed through an end-to-end engineering workflow.

**Propellants:** Ethanol / GOX

### Engineering Pipeline

```text
CEA PERFORMANCE MODEL
        ↓
INJECTOR DESIGN
        ↓
NOZZLE DESIGN
        ↓
CATIA CAD
        ↓
CNC / LATHE MACHINING
        ↓
ASSEMBLY
        ↓
STATIC FIRE
        ↓
DATA ANALYSIS
        ↓
ITERATION
```

### First Static-Fire Result

| Parameter        |    Result |
| ---------------- | --------: |
| Predicted thrust | **130 N** |
| Measured thrust  | **121 N** |
| Difference       | **~6.9%** |

**Focus:** Liquid propulsion · Injector design · Nozzle design · Manufacturing · Testing
